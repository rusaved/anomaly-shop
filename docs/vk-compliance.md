# Соответствие правилам VK и ОК («Ресейл 16», V-12; «Ресейл 17», P-06)

Сборка `dist-vk` (`npm run build:vk`), на Pages — https://rusaved.github.io/anomaly-shop/vk/ (собирает `npm run build:pages`). Одна сборка на обе площадки: VK или ОК определяется по параметрам запуска (`vk_client=ok` или `vk_platform=*_ok` → ОК). Проверки: `npm run check:vk` (файлы сборки), `tests/vk.test.ts` (unit на заглушке моста), `npm run e2e:vk` (`e2e/vk-v.spec.ts`, опубликованная структура `dist-pages`), ревизоры `docs/evidence/V/usability.md` и `docs/evidence/V/moderator.md`.

Перед подачей штабу: заполнить в `content/vk.json` appId и okGroupId (vkGroupId 242262788 заполнен 27.10) — Q-066. Документы — типовые документы VK, выбранные в панели VK; своих страниц документов нет, /legal/ не публикуется (P-06).
