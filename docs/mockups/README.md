# Макеты мобильного интерфейса (веха MU «Мобильный интерфейс»)

PNG сняты со страницы макетов штаба. Портрет: рамка 375×650 CSS px (видимая зона игры на телефоне под панелями браузера), на картинке 1 CSS px = 1,6 px. Альбом: 812×330 CSS px (по нему и приёмка, `07` «Приёмка»), 1 CSS px ≈ 0,89 px. Правила, токены и словарь — `docs/07-mobile-ui.md`. Арт условный: яйца, питомцы и значки — заглушки; верх сцены «Лавки» — кадр сборки.
