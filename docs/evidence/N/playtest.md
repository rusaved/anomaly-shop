## 3 худших момента
1. **170s**: тапал яйцо, а окно «Вылупился!» встало поверх, и «Продать сразу» оказалось ровно под пальцем (кнопка 33–233×145–189, яйцо 118,148). Редкий «ценный» продан за 62, я его не видел. Кадр `docs/evidence/N/playtest/815-228s-hatch.png`.
2. **249s**: подсказка «Покорми его тапами», а тап по питомцу открывает «Цену» с ползунком. Кормёжки нет (`fed 0`, `levelUps 0`). Кадр `docs/evidence/N/playtest/815-249s-feed.png`.
3. **338–360s**: подсвечена «10» под «Купи новое яйцо», 21 монета, два тапа без отклика (через `click` по селектору покупка прошла). Кнопка у самого края над вкладками, подпись «Обычное яйцо» перекрыта подсказкой. Подозрение: блок перерисовывается каждую секунду (таймер «через 1:52», ссылки snapshot тоже живут меньше секунды), и нажатие с отпусканием попадают в разные элементы. Кадр `docs/evidence/N/playtest/815-360s-buy2.png`.

## 3 правки по важности
1. Окно вылупления не показывать под пальцем: 0,5 с не принимать тапы или убрать «Продать сразу» из зоны яйца. Редкое продавать только после показа.
2. Сделать шаг «покорми»: тап по питомцу на витрине растит уровень и цену с «+N». Цену открывать отдельной кнопкой или вторым тапом.
3. Не перерисовывать кнопки покупки по тику таймера, обновлять только текст. В альбоме 290 px поднять ряд «Обычные» над вкладками, подсказку не класть на название.

Ещё: интерстишл на 251s при входе в «Чаты» (по правилам, но сразу после тапа); «Скорость вылупления» советуется, когда оба инкубатора пусты (315s).

## Пилот Playwright CLI
- Команд CLI: ~145 (один тап по canvas — 3 команды, ~1,5 с каждая).
- Легко: `open` с конфигом, `snapshot` с понятными ролями, `eval` для `state()`/`targets()`, `screenshot --filename`, `click` по CSS-селектору.
- Трудно: ссылки `eNN` живут меньше секунды (перерисовка), `click eNN` падал с «Ref not found». Обход: `click "[data-action=…]"` или `nav button:has-text('Лавка')`. `mousedown`/`mouseup` по HTML-кнопке не сработал. Задержка 1–1,5 с на команду: тапать «как человек» (серия 3 быстрых тапов) нельзя, темп первой минуты завышен (продажа на 122s отчасти из-за меня). Ожиданий нет, только `sleep`.
- Снова так играть: да, для разведки и пунктов 1, 4, 6–8. Для темпа и сочности нужен скрипт или пакетный тап (несколько действий в одной команде).
