# Готовность к подаче в Яндекс Игры — что осталось продюсеру

M7, 25.10.2026, сессия по расписанию. Технически релиз-кандидат готов: отчёт соответствия `docs/evidence/compliance/report.md` — 66 пунктов, FAIL 0, TODO 0; check-release 8/8; первый экран 2,9 с на 4G и слабом процессоре; бот 10 минут без ошибок; плейтест 3,71

## 1. Архив
- Файл: `downloads/anomaly-shop-0.1.0.zip` (639 КБ). Скачать: github.com/rusaved/anomaly-shop → папка `downloads` → файл → кнопка «Download raw file»
- `anomaly-shop-0.1.0-playtest.zip` в Консоль не загружать: это сборка на моке

## 2. Консоль разработчика → черновик игры (готовые значения)
| Поле | Значение |
|---|---|
| Языки | русский, английский |
| Возрастной рейтинг | 6+ |
| Устройства | компьютер, телефон, планшет |
| Ориентация на телефоне | обе (игра сама перестраивается) |
| Облачные сохранения | включить |
| Сообщество | две группы, в названии «Яндекс Игры» (сейчас в игре: t.me/sunhearth_games и vk.ru/sunhearth_yandex) |
| Название, описание, обложки, «Как играть» | позже, решение продюсера 24.10 (черновик «Как играть» ниже) |

Черновик поля «Как играть» (ru), правьте как удобно:
«Тапни яйцо, и из него вылупится питомец. Тапай питомца, чтобы покормить: так растёт его цена. Выставь его на продажу и договорись с покупателем в «Чатах». На монеты покупай новые яйца и улучшения лавки»

## 3. Метрика
Создать счётчик Метрики и прислать номер: сборщик впишет его в `game.json → metrikaCounterId` (сейчас 0) и пересоберёт архив

## 4. Реклама
Подключить рекламу (договор ЕЛС или РСЯ), включить полноэкранную и «за награду». Стики-баннер на телефоне лучше выключить (на ПК игра уступает ему место сама)

## 5. Покупки (по желанию, сейчас выключены)
Создать товары в Консоли с этими id и ценами, затем написать «включить покупки» — сборщик переключит `game.json → profiles.yandex.payments` и пересоберёт архив
| id товара | Название | Цена, ян |
|---|---|---|
| pack_starter | Набор новичка | 49 |
| pack_season | Сезонный набор | 79 |
| pack_mega | Мега-набор | 149 |
| coins_s | Горсть монет | 19 |
| coins_m | Мешок монет | 59 |
| coins_l | Сундук монет | 129 |
| no_ads | Без рекламы | 99 |

## 6. Проверить на телефонах (черновик с `&debug-mode=16`)
1. Яндекс Браузер и Chrome на Android, Safari на iPhone: игра открывается, звук есть
2. Сверните игру и вернитесь: звук стихает и возвращается
3. Пройдите первую минуту только тапами
4. «Настройки» → тап по полю промокода: клавиатура не закрывает поле
5. Реклама в обеих ориентациях телефона
6. Вкладка IT черновика без ошибок
