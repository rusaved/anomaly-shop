# Бриф «Ресейл 10 · Техническая готовность» (RD)

Из задания продюсера по расписанию (22.10: вехи идут одна за другой без его проверки, приёмка общим прогоном в понедельник). Записан сборщиком дословно по сути, без правок.

Цель: игра технически готова к подаче: проверки автоматические, бюджет и баланс измерены, кадры всех окон на телефоне продюсера.

- RD-01 CI: полный verify в GitHub Actions на push в main; сессия читает итог прогона, а не весь лог.
- RD-02 Правдивые кадры: все окна и вкладки списком из кода окон на 880×405 и 815×290; автопроверка «кнопка видна целиком».
- RD-03 sim:balance ботами (p50, p90): первая покупка, стена, доход офлайн против активной игры; правки чисел только в content/ с записью «было → стало».
- RD-04 Производительность: первый экран ≤ 5 с на 4G, FPS ≥ 30 при CPU ×4, память без роста за 10 минут.
- RD-05 check-release: скрипт требований Яндекса по docs/03 — размер архива, SDK, ни одной внешней ссылки, звук только Web Audio, ключи языков.
- RD-06 Матрица устройств qa/device-matrix.md и e2e-профили mobile, desktop, webkit.

Вкусовых правок (вид, тексты, баланс по ощущению) не делать — только вопросом в QUESTIONS.md. Ревизор: удобство (по кадрам RD-02).

Итог: полный verify один раз (плюс один повтор); «Что проверить продюсеру» 5 шагов без кодов вопросов, первой строкой https://rusaved.github.io/anomaly-shop/; «Хрупкое» до 3; «проверено / не проверено»; «Сессия: старт, конец»; «сверено со сводом»; последней строкой «Ждёт решения продюсера»; `git push origin HEAD:main`.
